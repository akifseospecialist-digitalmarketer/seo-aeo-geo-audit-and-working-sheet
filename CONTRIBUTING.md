# Contributing

Thanks for helping improve this prompt. Useful contributions include:

- **New checks** — technical, AEO or GEO tests that belong in the audit.
- **Country packs** — local directories, review sites and search databases for markets outside Australia.
- **Threshold tweaks** — better limits for titles, descriptions, word counts or difficulty bands, with a reason.
- **Agent results** — notes on how the prompt performs in other AI agents or with other SEO tools.
- **Bug fixes** — formulas that break, ambiguous instructions, tabs that come out wrong.

## How to contribute

1. Fork the repo and create a branch: `git checkout -b my-change`.
2. Edit `prompt.md` (and `docs/workbook-structure.md` if you change a tab or column).
3. Add a line to `CHANGELOG.md` under an "Unreleased" heading.
4. Open a pull request explaining what changed and why. If you tested it, say which agent and tools you used.

## Guidelines

- Keep the prompt in plain, direct English — short sentences, no filler.
- Don't add anything that encourages the agent to guess or invent numbers.
- Keep example businesses fictional. Never commit real client data, reports or screenshots.
- One change per pull request where possible.

## Reporting issues

Open an issue with the agent you used, the tools connected, what you expected, and what happened. Remove any client details first.
