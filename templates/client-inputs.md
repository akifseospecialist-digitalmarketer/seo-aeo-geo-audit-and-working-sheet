# Client Inputs Template

Fill this in, then paste it over section 1 of the prompt in [`prompt.md`](../prompt.md).

Leave a field blank if you don't know it — the agent will look it up from the website, uploaded files and connected tools, and only ask you about what it can't find.

```text
Business name (exact, full):       
Brand name to use in content:      
Website:                           
Business location (city, state):   
Target service area:               
Country / search database:         
Customer types:                    
Primary audience:                  
Typical budget / job size:         
Primary service (priority 1):      
Secondary service (priority 2):    
Other services:                    
Services NOT offered:              
Known competitors:                 
Brand-name collisions to watch:    
Existing assets:                   
Connected tools to use:            
```

## Field guide

| Field | What to put | Why it matters |
|-------|-------------|----------------|
| Business name (exact, full) | Legal/registered name, e.g. "Smith Flooring Pty Ltd" | Used for NAP and entity consistency checks |
| Brand name to use in content | The name customers know, e.g. "Smith Flooring" | Keeps content and schema consistent |
| Website | Full URL with protocol | Crawl and audit target |
| Business location | City and state | Sets the city-level SERP location |
| Target service area | Regions/suburbs served, and how far | Drives the Area Check and area-page keywords |
| Country / search database | e.g. Australia (google.com.au) | Keyword and SERP database |
| Customer types | Residential, commercial, industrial, etc. | Shapes keyword intent and content angle |
| Primary audience | Who you want most | Keeps priorities straight |
| Typical budget / job size | e.g. $3k–$15k | Helps qualify keywords and messaging |
| Primary service | The money service | Gets priority everywhere |
| Secondary service | Second priority | Ranked after primary |
| Other services | Anything else offered | Included but lower priority |
| Services NOT offered | Things to exclude | Agent flags content promoting these |
| Known competitors | Domains you already know | Added to the SERP-based competitor list |
| Brand-name collisions | Similar names, e.g. a same-name business in another state | GEO / AI brand-confusion check |
| Existing assets | GBP, socials, directories, past reports, photos | Off-page and GEO checks |
| Connected tools to use | e.g. SE Ranking, GSC, GA4, PageSpeed | Tells the agent which data sources to pull |
